# پرودید — فروشگاه اینترنتی 🥩

وب‌سایت فارسی فروشگاه **پرودید** (پروتئین هر خانه) — فروشگاه تخصصی مواد پروتئینی و فودشاپ در کاشان.

- 📍 کاشان، میدان عامریه، خیابان امیرکبیر محور چهاربانده، ۱۰۰ متر بعد از پیتزا دولپی (سابق)
- 📞 ۰۹۱۳۰۶۱۲۰۱۹
- 📷 اینستاگرام: [@PRODID1](https://www.instagram.com/prodid1/)

این پروژه با **Next.js 14 (App Router) + TypeScript** ساخته شده است (پیش‌تر یک سایت کاملا استاتیک HTML/CSS/JS بود که به‌صورت کامل به Next.js مهاجرت داده شد؛ ظاهر و رفتار سایت دقیقا حفظ شده است).

## امکانات سایت

- کاملا **فارسی و راست‌چین (RTL)** با فونت وزیرمتن (به‌صورت لوکال)
- طراحی **Mobile First** با منوی پایین مخصوص موبایل
- فروشگاه با **جست‌وجو، فیلتر دسته‌بندی، فیلتر نوع فروش (وزنی/عددی) و مرتب‌سازی**
- **سبد خرید** با ذخیره‌سازی در مرورگر (localStorage)
- پشتیبانی از **محصولات وزنی** (قیمت هر کیلو + پیام شفاف «مبلغ نهایی پس از وزن‌کشی»)
- **تسویه حساب** با انتخاب روز و بازه زمانی تحویل، روش پرداخت و توضیحات سفارش
- ثبت نهایی سفارش از طریق **واتس‌اپ** (بدون نیاز به سرور) + گزینه سفارش تلفنی
- **حساب کاربری ساده** (ذخیره مشخصات و تاریخچه سفارش روی دستگاه کاربر)
- **دستیار هوشمند** شناور با پاسخ به سوالات متداول و پیشنهاد دستور پخت
- صفحات: اصلی، فروشگاه، محصول، سبد، تسویه، حساب، درباره ما، تماس، ارسال و سفارش، سوالات متداول، قوانین

## ساختار پروژه

```
app/                    صفحات و مسیرهای Next.js (App Router)
  page.tsx              صفحه اصلی
  shop/, product/, cart/, checkout/, account/,
  about/, contact/, faq/, shipping/, terms/     بقیه صفحات
  layout.tsx             چیدمان مشترک (هدر، فوتر، منوی موبایل، دستیار هوشمند)
  globals.css             استایل کامل سایت
components/              کامپوننت‌های مشترک ری‌اکت (Header, ProductCard, Assistant, ...)
lib/
  data.ts                اطلاعات برند + دسته‌بندی‌ها + محصولات و قیمت‌ها
  cart.ts                منطق سبد خرید (localStorage + هوک ری‌اکتی)
  format.ts               فرمت اعداد فارسی و قیمت
  icons.tsx                مجموعه آیکن‌های SVG
public/assets/
  fonts/                  فونت وزیرمتن
  img/products/           عکس واقعی محصولات (اختیاری — پایین را بخوانید)
  img/categories/         عکس دسته‌بندی‌ها
```

## توسعه محلی

```bash
npm install
npm run dev
```

سپس آدرس `http://localhost:3000` را باز کنید.

برای بیلد نسخه‌ی نهایی:

```bash
npm run build
npm run start
```

## ویرایش محصولات و قیمت‌ها

همه محصولات در فایل [`lib/data.ts`](lib/data.ts) تعریف شده‌اند:

```ts
{ id: "kabab-koobideh", name: "کباب کوبیده", cat: "kebab",
  price: 830000, sale: "w", ic: "skewer", desc: "..." }
```

- `price`: قیمت به تومان (برای محصولات وزنی، قیمت هر کیلو). مقدار `null` یعنی «استعلام قیمت».
- `sale`: `"w"` وزنی / `"u"` عددی-بسته‌ای
- `available: false` محصول را «ناموجود» می‌کند.
- `badge`: برچسب دلخواه مثل «پرفروش» یا «ویژه»

## افزودن عکس واقعی محصولات

برای هر محصول کافی است عکسی با نام `<id>.jpg` در پوشه `public/assets/img/products/` قرار دهید
(مثلا `kabab-koobideh.jpg`). عکس به‌صورت خودکار جایگزین آیکن پیش‌فرض می‌شود؛ نیازی به تغییر کد نیست.

**عکس دسته‌بندی‌ها:** عکس هر دسته را با نام `<id>.jpg` در پوشه `public/assets/img/categories/`
بگذارید (مثلا `meat.jpg` برای گوشت و استیک). نام‌ها: meat، kebab، chicken، coldcuts،
burger، veg، salad، fresh، dairy، market.

## استقرار (Deploy)

از آنجا که سایت اکنون یک اپلیکیشن Next.js است (نه فایل‌های استاتیک ساده)، برای اجرا به یک محیط
Node.js نیاز دارد — مثلا [Vercel](https://vercel.com) (پیشنهادی و رایگان برای پروژه‌های Next.js)
یا هر هاست دیگری که از Node.js پشتیبانی می‌کند. میزبانی روی GitHub Pages دیگر ممکن نیست، چون
GitHub Pages فقط فایل استاتیک سرو می‌کند.

## قدم‌های بعدی پیشنهادی

- اتصال درگاه پرداخت آنلاین (مثل زرین‌پال) — نیازمند سرور/سرویس بک‌اند
- اتصال دامنه اختصاصی (مثلا `prodid.ir`)
- افزودن عکس‌های واقعی محصولات از اینستاگرام فروشگاه
- تکمیل دسته‌بندی‌های «به‌زودی» (پروتئینی تازه، لبنیات، اقلام سوپرمارکتی)
